# Project 3A: Dictionaries and Sets

## Overview

This project focuses on using dictionaries and sets in Python to organize, modify, and work with data. I created dictionaries to store NFL and NBA teams and their locations, along with sets containing Pennsylvania and Mid-Atlantic cities. The project allowed me to practice working with collections of data and performing different operations on them.

## What I Worked On

In this project, I practiced:

- **Creating and modifying dictionaries:** Storing NFL and NBA teams with their corresponding locations and adding new teams.
- **Working with sets:** Creating sets of cities and adding new cities.
- **Set operations:** Finding the union, intersection, and symmetric difference between sets.
- **Loops:** Iterating through dictionaries to display their items.
- **Keys and values:** Printing dictionary keys and values separately.
- **Merging and updating dictionaries:** Combining dictionary data and updating one dictionary with another.
- **Subset and superset checks:** Using comparison operators to determine the relationship between two sets.
